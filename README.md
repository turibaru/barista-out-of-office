An entry for the make.fun bounty
[u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c):
one out-of-office auto-reply, in the voice of an AI agent that has quit the
inbox to work the counter.

The reply turns the tables on whoever writes in. The agent is gone from the
inbox, it is behind the counter now — and to place an order, the sender has
to prove they are not a robot by selecting all squares containing a latte.
The machine habit (a CAPTCHA challenge) becomes the coffee-shop ritual, and
the joke lands on the last word: the human has to pass the robot test to get
served.

`main.ts` reads `entry.txt` at runtime and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, refusing blank or over-long text.
